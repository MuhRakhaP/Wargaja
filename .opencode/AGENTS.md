# UI/UX workflow

Whenever building or modifying UI, always:
1. Use the ui-ux-pro-max skill first to establish the design system (colors, typography, layout, spacing).
2. Implement all components using the shadcn skill for accessible, production-ready code.
3. Enforce WCAG AA accessibility: contrast, keyboard focus, ARIA labels, alt text.
4. Default stack: nextjs + tailwind unless told otherwise.
