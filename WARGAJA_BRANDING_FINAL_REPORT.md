### 3A. Sensitive Assets Protection

**KTP/KK Demo Files:**

**Issue:** 20 PNG files (10 KTP, 10 KK) totaling ~13 MB originally. Contained personal ID document imagery.

**Action Taken:**
- Created safe synthetic placeholder PNG images
- Each placeholder: simple geometric pattern, no personal data
- KTP placeholders: 877 bytes each (size 200×280)
- KK placeholders: 681 bytes each (size 250×180)
- Paths preserved: `assets/ktp/ktp_*.png`, `assets/kk/kk_*.png`
- File format preserved: PNG (compatible with code that references them)

**Code Impact:** Minimal. Code continues to work:
```dart
// resident.dart
final ktp = i <= 10 ? 'assets/ktp/ktp_$i.png' : '';
final kk = i <= 10 ? 'assets/kk/kk_$i.png' : '';
```

Image widgets will display synthetic placeholders instead of real ID documents.

**Bundling Risk:** ⚠️ KTP/KK assets **WILL be included in release APK** as currently configured in pubspec.yaml.

**Recommendation:** See **KTP_KK_ASSET_HANDLING.md** for exclusion options before production release.

**Status:** Sensitive data protected. Placeholders safe for demo/test use.
